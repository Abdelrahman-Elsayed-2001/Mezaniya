# ميزانيتي الشهرية

تطبيق ويب لإدارة الميزانية الشهرية، حُوِّل من ملف `mezaniya.xlsx`. يدعم أكثر من مستخدم على الشبكة الداخلية، وبيانات كل مستخدم منفصلة تمامًا عن غيره، ويعمل باللغتين العربية والإنجليزية.
تفاصيل الحسابات والقرارات في [PLAN.md](PLAN.md).

## التشغيل

**المتطلبات:** Python 3 على ويندوز. لتنزيل المشروع من GitHub:
```bash
git clone https://github.com/Abdelrahman-Elsayed-2001/Mezaniya.git
```

**الطريقة الأسهل:** انقر نقرًا مزدوجًا على `start.bat`.
- في المرة الأولى: يُنشئ `.venv` ويثبّت المكتبات.
- في كل مرة: يشغّل الخادم.

**أو يدويًا:**
```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

عند تشغيل الخادم يطبع عناوينه:
- `http://localhost:8080` من الجهاز نفسه.
- `http://192.168.x.x:8080` من أي جهاز آخر على الشبكة (هاتف أو حاسوب).

في المرة الأولى: افتح العنوان واضغط **«تسجيل مستخدم جديد»**.

## اللغة

- زر **English / العربية** في أعلى كل صفحة يبدّل اللغة لهذا المتصفح، ويقلب اتجاه الصفحة تلقائيًا.
- `MEZANIYA_LANGUAGE` يحدد اللغة الافتراضية للزائر الجديد، ولغة مدير الخادم والسجل و`manage.py`.
- **جميع نصوص البرنامج** في ملف واحد: [app/i18n/strings.json](app/i18n/strings.json)، وفيه كل نص بالعربية والإنجليزية جنبًا إلى جنب. لا توجد نصوص مكتوبة داخل ملفات البرمجة.
- أنواع المصروفات والأهداف الافتراضية تُنشأ بلغة المستخدم عند تسجيله، ويمكنه تغيير أسمائها لاحقًا.

## المستخدم التجريبي

لتجربة البرنامج ببيانات جاهزة: زر **«مستخدم تجريبي (test)»** في مدير الخادم، أو:
```bash
.venv\Scripts\python.exe manage.py demo
```
يُنشئ المستخدم `test` بكلمة المرور `test123`، ومعه بيانات **ثلاثة أشهر** تنتهي بالشهر الحالي: بنود متكررة، وأقساط، وترحيل جزئي، وبند غير مدفوع رُحِّل، ومدفوعات بتواريخها، وأهداف. استخدم `--replace` لإعادة إنشائه ببيانات جديدة.

## الأشهر

- **شهر بعد آخر شهر:** يُنسخ من آخر شهر عبر نافذة «شهر جديد»، فتنتقل الأرصدة والتقسيط والبنود المتكررة والمبالغ المرحَّلة والأهداف.
- **شهر قبل آخر شهر** (لإدخال بيانات سابقة): يُنشأ فارغًا **دون ترحيل تلقائي**، ويمكن إضافة البنود المتكررة إليه بزر «+ البنود المتكررة».
- يحفظ كل شهر الشهرَ الذي نُسخ منه، ولا تتزامن المبالغ المرحَّلة إلا عبر هذا الربط، فلا يصل ترحيل إلى شهر لم يُنسخ منه.
- يمكن حذف أي شهر، ما لم يكن قد نُسخ منه شهر آخر، وبشرط أن يبقى شهر واحد على الأقل.

## مدير الخادم (واجهة رسومية)

انقر نقرًا مزدوجًا على **`manager.bat`**. يفتح دون نافذة سوداء، ومنه يمكنك:

| | |
|---|---|
| **الخادم** | التشغيل والإيقاف وإعادة التشغيل والفتح في المتصفح. يجد الخادم سواء شُغّل من المدير أو من `start.bat` أو من محرر الشيفرة. |
| **المنفذ** | «حفظ المنفذ» يكتبه في `mezaniya.env`، وينسخ أمر الجدار الناري للمنفذ الجديد، ويعرض إعادة التشغيل. |
| **المتصلون الآن** | من استخدم البرنامج خلال آخر 15 دقيقة يظهر بالأخضر. |
| **الإخراج** | «إخراج المستخدم» لمستخدم واحد، أو «إخراج جميع المستخدمين». يحدث الخروج فورًا من جميع الأجهزة دون إعادة تشغيل الخادم. |
| **مستخدم جديد** | اسم وكلمة مرور. يعمل حتى لو كان التسجيل من الموقع مغلقًا. |
| **مستخدم تجريبي** | يُنشئ `test` ببيانات ثلاثة أشهر (أو يعيد إنشاءه). |
| **تغيير كلمة المرور** | بالنقر المزدوج على المستخدم أو بالزر. خيار «مؤقتة» يجعله يكتبها بين علامتي `#...#` ويغيّرها عند أول دخول. يخرج المستخدم من جميع الأجهزة. |
| **حذف المستخدم وجميع بياناته** | يتطلب كتابة اسمه للتأكيد، وتُنشأ نسخة احتياطية قبل الحذف. |
| **نسخة احتياطية الآن** | مع فتح مجلد النسخ. |
| **سجل الخادم** | آخر أسطر السجل، ويتحدّث تلقائيًا. |
| **English / العربية** | يبدّل لغة المدير وينعكس اتجاه الواجهة. |

عند إغلاق المدير والخادم يعمل، يسألك: إيقافه، أو تركه يعمل وإغلاق المدير فقط.

## الإعدادات (`mezaniya.env`)

انسخ `mezaniya.env.example` إلى ملف باسم `mezaniya.env` وعدّل ما تحتاج. أهم الإعدادات:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `MEZANIYA_HOST` | `0.0.0.0` | `0.0.0.0` = متاح على الشبكة، `127.0.0.1` = هذا الجهاز فقط |
| `MEZANIYA_PORT` | `8080` | المنفذ |
| `MEZANIYA_LANGUAGE` | `ar` | اللغة الافتراضية (`ar` أو `en`) |
| `MEZANIYA_ALLOW_REGISTRATION` | `true` | اجعله `false` بعد أن يسجّل جميع المستخدمين |
| `MEZANIYA_DATA_DIR` | `data` | مكان قاعدة البيانات ومفتاح الجلسات والنسخ الاحتياطية والسجلات |
| `MEZANIYA_BACKUP_INTERVAL_HOURS` | `24` | نسخة احتياطية كل كم ساعة (`0` = متوقف) |
| `MEZANIYA_BACKUP_KEEP` | `14` | عدد النسخ الاحتياطية المحفوظة |

أي متغير بيئة بالاسم نفسه يتقدّم على الملف.

## الوصول من الشبكة (الجدار الناري في ويندوز)

يغلق ويندوز المنفذ افتراضيًا. افتح **PowerShell بصلاحيات المسؤول** واكتب:

```bash
New-NetFirewallRule -DisplayName "Mezaniya" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private
```

- `-Profile Private` تعني فتح المنفذ على الشبكات الخاصة فقط (المنزل أو العمل)، لا على الشبكات العامة.
- تأكد أن الشبكة معرّفة في ويندوز على أنها «Private».
- لإزالة القاعدة: `Remove-NetFirewallRule -DisplayName "Mezaniya"`.

> الاتصال يتم عبر HTTP دون تشفير، وهذا مناسب للشبكة الداخلية فقط. إذا أردت إتاحته على الإنترنت فضع أمامه HTTPS، مثل Caddy أو وكيل عكسي.

### التشغيل التلقائي مع ويندوز (اختياري)
**Task Scheduler** ← Create Task:
- **Trigger:** At log on (أو At startup).
- **Action:** `start.bat`، و**Start in** = مجلد المشروع.

## النسخ الاحتياطي

- **تلقائي:** ما دام الخادم يعمل، تُنشأ نسخة كل 24 ساعة في `data\backups\mezaniya-YYYYMMDD-HHMMSS.db`، ويُحتفظ بآخر 14 نسخة فقط. تُنشأ النسخ بطريقة آمنة أثناء عمل الخادم.
- **يدوي:**
  ```bash
  .venv\Scripts\python.exe manage.py backup
  ```
- **الاسترجاع:** أوقف الخادم أولًا، ثم:
  ```bash
  .venv\Scripts\python.exe manage.py list-backups
  ```
  ```bash
  .venv\Scripts\python.exe manage.py restore data\backups\mezaniya-20261101-030000.db --yes
  ```
  قبل الاسترجاع تُحفظ قاعدة البيانات الحالية نسخةً احتياطية تلقائيًا.

💡 يُفضَّل أن يكون `MEZANIYA_BACKUP_DIR` على قرص آخر، أو في مجلد يتزامن مع OneDrive.

## نسيان كلمة المرور

**الطريقة الأولى (الأسهل):** من مدير الخادم ← «تغيير كلمة المرور» مع خيار «مؤقتة»، أو:
```bash
.venv\Scripts\python.exe manage.py reset-password اسم_المستخدم
```
يطبع كلمة مرور مؤقتة مثل `#a1B2c3d4#`، ويمكنك اختيارها بنفسك عبر `--password "#1234#"`.

**الطريقة الثانية:** افتح قاعدة البيانات بأي برنامج SQLite، واكتب في `users.password_hash` قيمة مثل `#1234#`.

**في الحالتين:**
- يكتب المستخدم كلمة المرور **مع العلامتين** (`#1234#`).
- يطلب منه التطبيق كلمة مرور جديدة فورًا.
- يخرج من أي جهاز كان مسجّلًا عليه.

## أوامر الإدارة

```bash
.venv\Scripts\python.exe manage.py list-users
```
وكذلك: `reset-password`، و`logout-all`، و`delete-user <الاسم> --yes`، و`demo`، و`backup`، و`list-backups`، و`restore`، و`migrate`. تتبع رسائلها `MEZANIYA_LANGUAGE`، أو الخيار `--lang en`.

## الملفات المهمة

| المسار | المحتوى |
|---|---|
| `data\mezaniya.db` | قاعدة البيانات، وفيها بيانات جميع المستخدمين |
| `data\secret_key` | مفتاح تأمين جلسات الدخول. إذا حُذف يخرج جميع المستخدمين فقط |
| `data\backups\` | النسخ الاحتياطية |
| `data\logs\mezaniya.log` | سجل التشغيل، ويبدأ ملفًا جديدًا كل يوم، ويُحتفظ بآخر 30 يومًا |
| `app\i18n\strings.json` | جميع نصوص البرنامج بالعربية والإنجليزية |

> ملف `mezaniya.xlsx` مرفوع كقالب فارغ (العناوين والمعادلات فقط، دون بيانات).
> مجلد `data\` وملف `mezaniya.env` غير مرفوعين إلى GitHub (مستثناة في `.gitignore`)، لأنها تحوي بيانات المستخدمين ومفتاح الجلسات والإعدادات المحلية. يُنشأ مجلد `data\` تلقائيًا عند أول تشغيل.

## للمطورين

```bash
.venv\Scripts\python.exe -m pytest
```

- **`app/engine/`:** الحسابات نفسها، دون Flask ودون قاعدة بيانات ودون نصوص عرض (تُرجع مفاتيح الترجمة). هي قلب المشروع، وفيها اختبار يطابق أرقام ملف الإكسيل.
- **`app/i18n/`:** ملف النصوص ودوال الترجمة وصيغ الجمع العربية.
- **`app/db/`:** بنية القاعدة، وترقياتها، وطبقة الوصول. كل استعلام مقيّد بـ `user_id`.
- **`app/api/`:** واجهة REST، و**`app/auth/`:** تسجيل الدخول.
- **`app/services/`:** الشهر الجديد، ومزامنة الترحيل، والنسخ الاحتياطي، والمستخدم التجريبي، وأوامر الإدارة.
- **`app/templates/` + `app/static/`:** الواجهة (Alpine.js مضمّن في المشروع، فلا حاجة إلى الإنترنت).
- يتحقق اختبار تلقائي من وجود كل نص بالعربية والإنجليزية بالمتغيرات نفسها، ومن أن كل مفتاح يستخدمه الكود موجود، ومن خلوّ ملفات البرمجة من النصوص العربية.
